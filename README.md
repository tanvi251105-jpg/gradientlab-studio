# 🎨 GradientLab Studio

GradientLab Studio is a modern gradient generator built using HTML, CSS, and JavaScript.

## Features

- Generate Random Gradients
- Create Custom Multi-Color Gradients
- Add and Remove Colors
- Preset Gradient Library
- Copy Gradient CSS
- Copy Individual Colors
- Dynamic Background Preview
- Responsive Dark-Themed UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
